You will need the following parts. This is for a build using the provided printed parts, and with
support for two IFS units. Notes may include information that may be helpful with custom builds.
AliExpress links are to the exact parts I used; if you're using my STLs too, it's probably best
to stick to these same ones.

- 1x RP2040 Zero or clone
    AliExpress: https://www.aliexpress.com/item/1005006648887091.html
    Notes: Make sure to get one with the pin headers already soldered on. Also, if doing a custom
           build, any RP2040-based board (eg. Raspberry Pi Pico) with MicroPython should work.

- 3x MAX3485 board
    AliExpress: https://www.aliexpress.com/item/1005008338314594.html
    Notes: These seem to break easily (or maybe just have a high dud rate), I recommend ordering a
           couple more than you need. If you want to add extra IFSes, you need one more of these
           for each additional IFS.
           
- 24V to 5V step-down converter
    AliExpress: https://www.aliexpress.com/item/1005008609313653.html
    Notes: Make sure to select the 5V one.
           
- 5x DuPont splitter board
    AliExpress: https://www.aliexpress.com/item/1005006998378039.html
    Notes: If doing a custom setup, you need to be able to join together:
        - a 4-way split for +24V DC (+1 per extra IFS)
        - a 12-way split for GND (+3 per extra IFS)
        - a 4-way split for +3.3V DC (+1 per extra IFS)
        - a 3-way split for UART1 TX (+1 per extra IFS)
        - a 3-way split for UART1 RX (+1 per extra IFS)
        - +5V DC is also connected through one of these, but it only actually has two connections,
          so you could just wire that one directly (I did it via this because I had spare space,
          and for potential future addons)
          
- 3x Microfit 3.0 4-pin (2x2) female connectors
    AliExpress: https://www.aliexpress.com/item/1005009306800581.html
    Notes: The shortest length is fine, you'll probably want to cut them even shorter than that.
           You will need one extra of these for each additional IFS you want to add.
           
- USB power splitter
    AliExpress: https://www.aliexpress.com/item/1005007166336240.html
    Notes: Not strictly *needed*, you can just disconnect the 24V stepdown before connecting USB
           (and the build includes a way to make this doable without opening the unit), but this
           makes things much more convenient. Note that this is not installed inside the IFS
           Jacker, it's just used when connecting to it via USB.
           
- DuPont terminal crimping kit
    AliExpress: https://www.aliexpress.com/item/1005008296406381.html
    Notes: Make sure to get the DuPont one, not the XH2.54 one. It may also be worth getting some
           spare female pin connectors if you aren't experienced with terminating them - you will
           probably mess up more often than you succeed at first.
           If you plan to use stuff you already have - be aware you need the male pin connectors
           too; not all kits include those. You'll need a variety of sizes of the plastic connector
           blocks ranging from 1 pin to 5 pin (you do not need 2x2's).
           
- 24 AWG wire, at least 5 different colors (7 is better, 9 is better again)
    AliExpress: https://www.aliexpress.com/item/1005008467990750.html
    Notes: Altogether, there are 9 different kinds of connections running here, which ideally you'd
           use a different color for each - but in my case, I only had the 5 colors (black, red,
           white, orange, yellow). The types are: +24V DC, +5V DC, +3.3V DC, UART TX, UART RX,
           RS485 A, RS485 B, RS485 EN pin, and GND. My color scheme was:
               +24V DC, +5V DC, +3.3V DC: Red
               GND: Black
               EN pin: White
               UART TX, RS485 A: Yellow
               UART RX, RS485 B: Orange
          Also, I erred on the side of safety in picking 24 AWG. 26 AWG is probably fine. But 24
          works, so there's little reason not to use it.
          I didn't measure the exact amount used. But if you buy that kit, you should have enough
          to make the IFS Jacker several times over.
